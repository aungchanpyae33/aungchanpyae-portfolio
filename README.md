## Run Locally

### Prerequisites

- **Node.js**: version `>22`
- **Package Manager**: `pnpm`(recommended)

---

### 1. Clone the Project

Bash

```
git clone https://github.com/aungchanpyae33/aungchanpyae-portfolio.git
```

```
cd aungchanpyae-portfolio
```

```
pnpm install
```

```
pnpm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
